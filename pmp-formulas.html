Core Measurements

Planned Value (PV)EVM
PV = % Planned Complete × BAC

Work that should have been completed by a specific point in time.

BACBudget at Completion (total project budget)

Worked Examples

Example 1 — Website Redesign

Project BAC = $100,000. By week 4 of 10, the plan says 40% of work should be done.

PV = 40% × $100,000 = $40,000

$40,000 of work should have been completed by now.

Example 2 — Software Sprint

A 6-month project with BAC = $240,000 is 3 months in. Plan called for 50% completion.

PV = 50% × $240,000 = $120,000

$120,000 worth of work was planned to be done at this midpoint.

Earned Value (EV)EVM
EV = % Actually Complete × BAC

The value of the work that has actually been accomplished.

Worked Examples

Example 1 — Construction Project

BAC = $500,000. The team has actually completed 35% of scope.

EV = 35% × $500,000 = $175,000

$175,000 worth of work has been earned.

Example 2 — IT Rollout (behind plan)

BAC = $80,000. Plan was 60% complete, but only 45% is actually done.

EV = 45% × $80,000 = $36,000

Only $36,000 of value has been earned (vs. $48,000 planned).

Actual Cost (AC)EVM
AC = Actual cost incurred

Total cost actually spent to accomplish the work measured by EV.

Worked Examples

Example 1 — Reading AC from context

The project has spent $55,000 in labor, $10,000 in materials, and $5,000 in overhead so far.

AC = $55,000 + $10,000 + $5,000 = $70,000

AC = $70,000. This is the input you use in CV, CPI, ETC, and EAC formulas.

Variances

Cost Variance (CV)Variance
CV = EV − AC

Positive = under budget. Negative = over budget.

Worked Examples

Example 1 — Under budget

EV = $50,000, AC = $45,000.

CV = $50,000 − $45,000 = +$5,000

Positive CV: project is $5,000 under budget.

Example 2 — Over budget

EV = $30,000, AC = $38,000.

CV = $30,000 − $38,000 = −$8,000

Negative CV: project is $8,000 over budget. Needs corrective action.

Schedule Variance (SV)Variance
SV = EV − PV

Positive = ahead of schedule. Negative = behind schedule.

Worked Examples

Example 1 — Ahead of schedule

EV = $60,000, PV = $50,000 (more work done than planned).

SV = $60,000 − $50,000 = +$10,000

Positive SV: project is ahead of schedule by $10,000 of work value.

Example 2 — Behind schedule

PV = $75,000, but only EV = $60,000 of work is done.

SV = $60,000 − $75,000 = −$15,000

Negative SV: project is behind schedule by $15,000 of planned value.

Performance Indices

Cost Performance Index (CPI)Index
CPI = EV ÷ AC

Efficiency of cost usage. CPI > 1 = under budget, < 1 = over budget.

⚑ Most important EVM efficiency metric on the exam.

Worked Examples

Example 1 — Efficient project

EV = $80,000, AC = $70,000.

CPI = $80,000 ÷ $70,000 = 1.14

Getting $1.14 of value per dollar spent. Project is under budget.

Example 2 — Over-spending

EV = $40,000, AC = $55,000.

CPI = $40,000 ÷ $55,000 = 0.73

Only $0.73 of value per dollar spent. Project is over budget.

Example 3 — Exam interpretation question

"The CPI is 0.85. What does this mean for the project?"

CPI = 0.85 → spending $1.00 to get $0.85 of value

The project is over budget — only 85 cents of value produced per dollar spent.

Schedule Performance Index (SPI)Index
SPI = EV ÷ PV

Efficiency of schedule usage. SPI > 1 = ahead of schedule.

Worked Examples

Example 1 — Exactly on track

EV = $50,000, PV = $50,000.

SPI = $50,000 ÷ $50,000 = 1.0

SPI = 1.0: project is exactly on schedule.

Example 2 — Behind schedule

EV = $30,000, PV = $45,000.

SPI = $30,000 ÷ $45,000 = 0.67

Only accomplishing 67% of planned work. Significantly behind schedule.

Forecasting

Estimate at Completion (EAC) — 3 variantsForecast
EAC = BAC ÷ CPI

If current CPI trend continues for the rest of the project.

EAC = AC + (BAC − EV)

If the remaining work will be done at the originally planned rate.

EAC = AC + [(BAC − EV) ÷ (CPI × SPI)]

If both cost and schedule performance affect remaining work.

Worked Examples

Variant 1 — CPI trend continues

BAC = $200,000, CPI = 0.80.

EAC = $200,000 ÷ 0.80 = $250,000

If inefficiency continues, the project will cost $250,000 — $50,000 over budget.

Variant 2 — Remaining work at planned rate

BAC = $200,000, AC = $90,000, EV = $70,000.

EAC = $90,000 + ($200,000 − $70,000) = $220,000

Assuming remaining work proceeds on budget, total cost will be $220,000.

Variant 3 — Both CPI and SPI considered

BAC = $200,000, AC = $90,000, EV = $70,000, CPI = 0.78, SPI = 0.88.

EAC = $90,000 + [($200,000 − $70,000) ÷ (0.78 × 0.88)] = $90,000 + [$130,000 ÷ 0.686] = $90,000 + $189,500 ≈ $279,500

Factoring in both inefficiencies, the project is expected to cost ~$279,500.

Estimate to Complete (ETC)Forecast
ETC = EAC − AC

Cost remaining to finish the project from now.

Worked Examples

Example 1

EAC = $250,000, AC = $90,000 already spent.

ETC = $250,000 − $90,000 = $160,000

$160,000 more is needed to finish the project.

Example 2 — Near completion

EAC = $105,000, AC = $98,000 already spent.

ETC = $105,000 − $98,000 = $7,000

Only $7,000 remains to complete the project.

Variance at Completion (VAC)Forecast
VAC = BAC − EAC

Expected cost over/under budget at project end.

Worked Examples

Example 1 — Over budget at completion

BAC = $200,000, EAC = $230,000.

VAC = $200,000 − $230,000 = −$30,000

Projected to finish $30,000 over budget.

Example 2 — Under budget at completion

BAC = $150,000, EAC = $140,000.

VAC = $150,000 − $140,000 = +$10,000

Projected to finish $10,000 under budget.

To-Complete Performance Index (TCPI)Forecast
TCPI = (BAC − EV) ÷ (BAC − AC)

CPI efficiency required on remaining work to meet the BAC.

TCPI = (BAC − EV) ÷ (EAC − AC)

Use this version when the original BAC is no longer achievable.

Worked Examples

Example 1 — Can we still hit BAC?

BAC = $100,000, EV = $40,000, AC = $50,000.

TCPI = ($100,000 − $40,000) ÷ ($100,000 − $50,000) = $60,000 ÷ $50,000 = 1.20

Must perform at 1.20 CPI on all remaining work — very aggressive target.

Example 2 — BAC revised upward

Same data, but a new EAC of $115,000 has been approved.

TCPI = ($100,000 − $40,000) ÷ ($115,000 − $50,000) = $60,000 ÷ $65,000 = 0.92

With the revised EAC, only 0.92 CPI is needed — more achievable.

Critical Path Method

Float (Slack)CPM
Float = LS − ES or LF − EF
LSLate Start
ESEarly Start
LFLate Finish
EFEarly Finish

⚑ Critical path activities have zero float.

Worked Examples

Example 1 — Activity with float

An activity has ES = Day 5, LS = Day 8.

Float = LS − ES = 8 − 5 = 3 days

This activity can be delayed up to 3 days without delaying the project.

Example 2 — Critical path activity

An activity has EF = Day 15, LF = Day 15.

Float = LF − EF = 15 − 15 = 0 days

Zero float — on the critical path. Any delay will delay the whole project.

Early Start / Early FinishCPM
EF = ES + Duration − 1

Forward pass: move left to right through the network. ES of successor = EF of predecessor + 1.

Worked Examples

Example 1 — First activity

Activity A starts on Day 1 and has a 4-day duration.

EF = 1 + 4 − 1 = Day 4

Activity A's earliest finish is Day 4.

Example 2 — Successor activity

Activity A finishes Day 4. Activity B (3-day duration) follows immediately.

ES(B) = EF(A) + 1 = Day 5 EF(B) = 5 + 3 − 1 = Day 7

Activity B runs Day 5 to Day 7.

Late Start / Late FinishCPM
LS = LF − Duration + 1

Backward pass: move right to left. LF of predecessor = LS of successor − 1.

Worked Examples

Example 1 — Last activity

Project must finish by Day 20. Last activity has a 5-day duration.

LF = Day 20 LS = 20 − 5 + 1 = Day 16

Last activity must start no later than Day 16.

Example 2 — Backward pass continuation

Last activity LS = Day 16. Preceding activity has a 4-day duration.

LF(preceding) = LS(last) − 1 = Day 15 LS(preceding) = 15 − 4 + 1 = Day 12

Preceding activity must start no later than Day 12 and finish by Day 15.

PERT (3-Point Estimating)

PERT Estimate (Beta)PERT
E = (O + 4M + P) ÷ 6
OOptimistic estimate
MMost Likely estimate
PPessimistic estimate

Worked Examples

Example 1 — Testing phase

O = 4 days, M = 7 days, P = 16 days.

E = (4 + 4×7 + 16) ÷ 6 = (4 + 28 + 16) ÷ 6 = 48 ÷ 6 = 8 days

The weighted estimate is 8 days. The most likely value gets the most weight (4×).

Example 2 — Symmetric distribution

O = 2 days, M = 5 days, P = 8 days.

E = (2 + 4×5 + 8) ÷ 6 = 30 ÷ 6 = 5 days

Symmetric range means the PERT estimate equals the most likely estimate.

PERT Standard DeviationPERT
σ = (P − O) ÷ 6

Measures the spread/uncertainty of the estimate.

Worked Examples

Example 1 — High uncertainty

O = 4 days, P = 16 days.

σ = (16 − 4) ÷ 6 = 12 ÷ 6 = 2 days

σ = 2 days. At 68% confidence (1σ), the range is 8 ± 2 = 6 to 10 days.

Example 2 — Low uncertainty

O = 4 days, P = 6 days.

σ = (6 − 4) ÷ 6 ≈ 0.33 days

Very small σ — tight range means high confidence in the estimate.

Triangular Distribution3-Point
E = (O + M + P) ÷ 3

Simpler than PERT beta — each estimate carries equal weight.

Worked Examples

Example 1 — Compare to PERT beta

O = 4 days, M = 7 days, P = 16 days.

Triangular: (4 + 7 + 16) ÷ 3 = 27 ÷ 3 = 9 days PERT beta: (4 + 28 + 16) ÷ 6 = 48 ÷ 6 = 8 days

Triangular gives 9 days vs. PERT's 8 days — the pessimistic value pulls the average higher.

Communication

Communication ChannelsComms
Channels = n(n − 1) ÷ 2

Total potential communication paths between n stakeholders.

⚑ Very frequently tested. With 10 people → 10×9÷2 = 45 channels.

Worked Examples

Example 1 — Small team

5 stakeholders on the project.

Channels = 5 × (5 − 1) ÷ 2 = 5 × 4 ÷ 2 = 10

10 communication channels to manage.

Example 2 — Adding one person

A new stakeholder joins, growing the team from 10 to 11 people.

Before: 10×9÷2 = 45 channels After: 11×10÷2 = 55 channels

Adding just one person adds 10 new channels — complexity grows rapidly.

Example 3 — Exam question style

A PM manages a project with 8 people (including themselves). How many channels?

Channels = 8 × (8 − 1) ÷ 2 = 8 × 7 ÷ 2 = 28

28 channels. Remember to include the PM in the count!

Procurement & Cost

Point of Total Assumption (PTA)Contract
PTA = ((Ceiling − Target Price) ÷ Buyer Share) + Target Cost

In a Fixed Price Incentive Fee (FPIF) contract — the cost point at which the seller absorbs all additional cost risk.

Worked Examples

Example 1 — FPIF Contract

Target Cost = $100,000 | Target Fee = $10,000 | Target Price = $110,000 | Ceiling = $130,000 | Share ratio = 70/30 (buyer/seller).

PTA = (($130,000 − $110,000) ÷ 0.70) + $100,000 = ($20,000 ÷ 0.70) + $100,000 = $28,571 + $100,000 = $128,571

If actual costs exceed $128,571, the seller bears 100% of all additional costs.

Contract Price (CPIF / CPFF)Contract
Price = AC + Fee

Cost-Plus contracts: buyer pays all actual costs plus an agreed fee (fixed, incentive, or award).

Worked Examples

Example 1 — CPFF (Fixed Fee)

Actual cost = $80,000, fixed fee = $10,000.

Price = $80,000 + $10,000 = $90,000

Buyer pays $90,000 regardless of seller efficiency.

Example 2 — CPIF (Incentive Fee)

Target cost = $100,000, AC = $90,000 (came in under). Seller gets 30% of savings as bonus. Base fee = $8,000.

Savings = $100,000 − $90,000 = $10,000 Incentive = 30% × $10,000 = $3,000 Fee = $8,000 + $3,000 = $11,000 Price = $90,000 + $11,000 = $101,000

Seller is rewarded for efficiency. Buyer still pays less than the $108,000 target price.

Project Selection

Net Present Value (NPV)Selection
NPV = Σ [FV ÷ (1 + r)ⁿ] − Initial Investment
FVFuture cash flow
rDiscount rate
nPeriod number

⚑ Higher NPV = better project. NPV > 0 means the project adds value.

Worked Examples

Example 1 — Choose between two projects

Project A NPV = $45,000. Project B NPV = $62,000. Same cost and risk profile.

Select Project B → higher NPV = more value created

On the exam, always choose the higher NPV project when all else is equal.

Example 2 — Calculate NPV

Project costs $50,000 today and returns $60,000 in Year 1. Discount rate = 10%.

PV of return = $60,000 ÷ (1.10)¹ = $54,545 NPV = $54,545 − $50,000 = +$4,545

NPV > 0: project creates $4,545 of value. Worth pursuing.

Return on Investment (ROI)Selection
ROI = (Net Benefits ÷ Costs) × 100%

Higher ROI = more attractive project. Used for benefit-cost comparisons.

Worked Examples

Example 1 — Compare two projects

Project A: Benefits = $150,000, Costs = $100,000.
Project B: Benefits = $90,000, Costs = $50,000.

ROI(A) = ($150,000 − $100,000) ÷ $100,000 × 100% = 50% ROI(B) = ($90,000 − $50,000) ÷ $50,000 × 100% = 80%

Project B has a higher ROI (80%) even though Project A has higher absolute returns.

Depreciation

Straight-Line DepreciationFinance
Depreciation = (Asset Cost − Salvage Value) ÷ Useful Life

Equal depreciation expense each year.

Worked Examples

Example 1 — Office equipment

Equipment costs $10,000, salvage value = $1,000, useful life = 5 years.

Depreciation = ($10,000 − $1,000) ÷ 5 = $9,000 ÷ 5 = $1,800/year

$1,800 is expensed each year for 5 years.

Double Declining BalanceFinance
Depreciation = (2 ÷ Useful Life) × Book Value

Accelerated method — higher depreciation in early years.

Worked Examples

Example 1 — Year 1 and Year 2

Asset cost = $10,000, useful life = 5 years.

Rate = 2 ÷ 5 = 40% Year 1: 40% × $10,000 = $4,000 → Book value = $6,000 Year 2: 40% × $6,000 = $2,400 → Book value = $3,600

Year 1 depreciation ($4,000) is more than double the straight-line rate ($1,800).

Risk

Expected Monetary Value (EMV)Risk
EMV = Probability × Impact

Used in decision tree analysis. Sum of all EMVs = Expected Value of a decision branch.

⚑ Risks use negative values; opportunities use positive values.

Worked Examples

Example 1 — Single risk

30% chance a vendor will be late, costing $20,000.

EMV = 30% × (−$20,000) = −$6,000

Reserve $6,000 for this risk in your contingency budget.

Example 2 — Decision tree

Build in-house: 60% chance of $50,000 gain, 40% chance of $30,000 loss.
Outsource: certain cost of $10,000.

EMV(in-house) = (60% × $50,000) + (40% × −$30,000) = $30,000 − $12,000 = +$18,000 EMV(outsource) = −$10,000

In-house has higher EMV ($18,000 vs. −$10,000). Choose in-house.

Example 3 — Mixed risks and opportunities

Risk A: 20% × −$15,000. Risk B: 10% × −$40,000. Opportunity: 25% × +$20,000.

EMV = (−$3,000) + (−$4,000) + ($5,000) = −$2,000

Net EMV is −$2,000. Reserve $2,000 in your contingency budget.

Contingency ReserveRisk
Reserve = Σ (Probability × Impact) per risk

Set aside for identified risks ("known unknowns"). Management reserve handles "unknown unknowns."

Worked Examples

Example 1 — Three identified risks

Risk 1: 50% × $10,000. Risk 2: 20% × $25,000. Risk 3: 10% × $50,000.

Reserve = $5,000 + $5,000 + $5,000 = $15,000

Add $15,000 to the budget as contingency for these known risks.

Quality

Cost of Quality (COQ)Quality
COQ = Cost of Conformance + Cost of Non-Conformance

Conformance = prevention + appraisal. Non-conformance = internal + external failure.

Worked Examples

Example 1 — Classify and calculate

Training = $5,000 (prevention). Testing = $3,000 (appraisal). Rework = $8,000 (internal failure). Customer refunds = $4,000 (external failure).

Conformance = $5,000 + $3,000 = $8,000 Non-Conformance = $8,000 + $4,000 = $12,000 COQ = $8,000 + $12,000 = $20,000

Non-conformance ($12,000) exceeds conformance ($8,000) — invest more in prevention upfront.

Control Chart — Rule of SevenQuality
Alert: 7 consecutive points on same side of mean

Seven consecutive data points above or below the mean signals a non-random pattern — even if within control limits.

Worked Examples

Example 1 — Rule triggered

Daily defect counts over 7 days: 3, 4, 5, 3, 4, 5, 4 — all above the mean of 2.5.

7 consecutive points above mean → Rule of Seven triggered

Even within control limits, the process is out of control. Investigate the cause.

Example 2 — Rule not triggered

Points alternate above and below the mean: high, low, high, low, high, low, high.

No 7 consecutive points on the same side → no action

The variation appears random. Process is in control.

Team & Human Resources

Tuckman's Team DevelopmentHR
Forming → Storming → Norming → Performing → Adjourning

Teams progress through stages; conflict (storming) is a normal part of development.

Worked Examples

Example 1 — Identify the stage

"Two team members are arguing about who owns a deliverable. The PM should..."

Stage: Storming — conflict over roles is expected here

Facilitate resolution and clarify roles. This is a normal stage, not a crisis.

Example 2 — High performance

"The team resolves issues independently and exceeds deliverable quality. What stage?"

Stage: Performing — self-directed and highly productive

Delegate and empower rather than micromanage.

Example 3 — End of project

"The project is complete and team members are being reassigned. What stage?"

Stage: Adjourning — team disbands after project closure

PM should recognize contributions and conduct lessons-learned sessions.

Maslow's Hierarchy of NeedsHR
Physiological → Safety → Social → Esteem → Self-Actualization

Lower-level needs must be met before higher-level motivators take effect.

Worked Examples

Example 1 — Safety need

"A team member is worried about potential layoffs. Which need is unmet?"

Safety needs — job security is a safety-level concern

Until safety needs are addressed, higher motivators like recognition won't be effective.

Example 2 — Self-actualization

A senior developer has all basic needs met and seeks more challenge and autonomy.

Self-Actualization — growth, creativity, reaching full potential

Assign stretch goals and creative ownership to keep them engaged.

Example 3 — Social need

"A remote team member feels isolated and disengaged despite good pay. What need is unmet?"

Social needs — belonging, teamwork, connection

Increase team interaction, pair programming, or virtual team events to address this.
